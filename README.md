# Phishing Detector

Ein Python-Projekt zur Erkennung von Phishing-E-Mails mit Machine Learning.

## Technologien
- Python
- pandas
- scikit-learn
- TF-IDF
- Logistic Regression

## Funktion
Das Modell analysiert den Inhalt von E-Mails und klassifiziert sie als:
- Phishing
- Legitimate E-Mail

## Start
```bash
pip install pandas scikit-learn
python main.py
